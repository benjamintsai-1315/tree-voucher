# Asana Scrum Ticket Template

```markdown
# Context
- 說明這件事為什麼要做
- 補充目前背景、問題、風險，或商業 / 產品脈絡
- 若有相關文件，可在此附上文件名稱或連結

# User Story
我是OOO，我想要做XXX，所以需要ZZZ

# To-do
- [ ] 列出要做的事項
- [ ] 若有細節請 reference SPEC 文件（SPEC: 文件名稱）
- [ ] 維持 action-oriented，避免寫成完整規格
```

## Notes

- `Context` 可用短段落或條列，但要讓接手的人知道為什麼這張 ticket 存在。
- `User Story` 沒有合適情境時，可寫：`不適用（純技術任務）`。
- `To-do` 只列要做的事，不展開規格；需要細節時用 SPEC reference。
